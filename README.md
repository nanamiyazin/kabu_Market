# KabuMarket — あつ森風カブ売買プラグイン（Paper 26.1.2）

## 遊び方
1. **日曜日の午前**にカブ売りのウリが来る → `/kabu` でカブを買う（10個単位、1個 90〜110）
2. **月曜〜土曜**は毎日 午前・午後の2回 買取価格が変わる → 高いときに `/kabu` で売る
3. **次の日曜日**になると、売れ残ったカブは「腐ったカブ」になって価値ゼロ

価格の動きは本家と同じ4パターン（波型・跳ね大型・減少型・跳ね小型）で、前週のパターンから今週のパターンが決まります。跳ね大型なら最大で購入価格の約6倍（600超）になります。相場はサーバー全体で共通です。

お金は **Vault 経由で経済プラグイン（EssentialsX など）のお金** を使います。
**Vault（または VaultUnlocked）と、Vault 対応の経済プラグインが必須**です。

## コマンド
| コマンド | 内容 |
|---|---|
| `/kabu` | 市場画面（GUI）を開く |
| `/kabu price` | 今週のカブ価（これまでの分）を表示 |
| `/kabu buy <個数\|max>` | カブを買う（日曜午前のみ） |
| `/kabu sell [個数\|all]` | カブを売る（月〜土） |
| `/kabu balance` | 所持金を見る |
| `/kabu admin info` | 今週のパターンと全価格を表示（OP） |
| `/kabu admin reroll` | 今週の相場を作り直す（OP） |

## 設定（config.yml）
- `time-mode: REAL` … 現実の曜日・時刻で進む（本家と同じ、1週間 = 現実の1週間）
- `time-mode: GAME` … マイクラ内の日数で進む（ゲーム内7日 = 1週間、約2時間20分）
  - テストやテンポ重視のサーバーにおすすめ。`/time add 24000` で1日進められます
- `price-multiplier` … カブ価に掛ける倍率（1.0 ならカブ1個 ≒ 100、0.1 なら ≒ 10）
- `bundle-size`, `announce-price-change` など

## その他の仕様
- カブはビートルート、腐ったカブは毒々しいジャガイモの見た目
- カブは食べる・クラフト・コンポスト・動物のエサ・村人との取引には使えません
- チェストやエンダーチェストに入れていても、週が変わった後に開くと腐ります
- 相場は `plugins/KabuMarket/market.yml` に保存（お金は経済プラグイン側で管理）

## ビルド
Java 25 が必要です（無い場合は Gradle が自動でダウンロードします）。

```
./gradlew build        # Windows は gradlew.bat build
```

`build/libs/KabuMarket-1.0.0.jar` をサーバーの `plugins/` に入れて再起動してください。
